# Entre Amis logo files

The designer's final logo, supplied 29 October 2026. The rules for using it are
in [`04-visual-identity.md`](../../04-visual-identity.md#logo); this page only
says which file is which.

## The four parts

| Part | What it is | Use it for |
| --- | --- | --- |
| `master` | Leaf, `ENTRE` and a script `amis`, side by side | The main logo, wherever it has room |
| `stacked` | The leaf above `ENTRE AMIS` in capitals | Square spaces |
| `leaf` | The leaf and its tendril, alone | The small mark: app top bar, app icon, seal |
| `brand-name` | `ENTRE AMIS` in capitals, no leaf | Small text lines, such as the app footer |

Each comes in **olive** (`#565A33`, the brand's deep olive), **black** and
**white**. White is for dark backgrounds, so on a white page it looks empty.

## The folders

| Folder | What's in it | Use it for |
| --- | --- | --- |
| `svg/` | The designer's SVG files, as supplied | Master copies; scale to any size |
| `svg-trimmed/` | The same SVGs cropped to the artwork | The app and the web (no empty margin) |
| `png/` | Transparent PNGs, olive / black / white | Screens, slides, documents |
| `jpg-rgb/` | Master and brand name in muted olive and charcoal, on white | Screens only; see the colour note below |
| `print-cmyk/` | Stacked and leaf in green and black, CMYK | Printers only, never screens |
| `archive/` | The retired September 2026 stacked caps logo | The record only; never use it |

## Notes

- The master PNGs sit on a large canvas with empty space around the artwork;
  trim them before use, or use `svg-trimmed/`. Trimmed files have been asked for
  from the designer.
- The RGB JPGs use a greyer olive (`#636445`) than the PNGs and SVGs, and add a
  charcoal (`#35363A`) that isn't in the Sous-bois palette. Use the PNG or SVG
  olive until the designer confirms which is meant.
- The CMYK files look brighter green on a screen. That is normal for print files;
  the printed colour depends on the printer's profile.
- `ENTRE` is drawn from Raleway Bold and `amis` from Malvides; both are
  outlined, so no font file is needed. Malvides is listed as free for personal
  and commercial use; its author welcomes a donation.
